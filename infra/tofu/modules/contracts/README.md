# Module contracts (KX-21 §01)

The product stack (`modules/product-stack`) depends on these ten contracts only. Each cloud ships one implementation
(`modules/aws/*` today; `modules/azure/*`, `modules/gcp/*` when needed). A new implementation MUST honour the inputs and
outputs below, so that `product-stack` and every `live/*` file stay unchanged except provider block and module source.
`ci-oidc` is an eleventh, AWS-specific helper used only by `bootstrap/`.

| # | Contract | AWS module | Required inputs | Required outputs |
|---|---|---|---|---|
| 1 | network | `aws/network` | `name`, `cidr`, `tags` | `vpc_id`, `public_subnet_ids`, `isolated_subnet_ids`, `connector_security_group_id`, `lambda_security_group_id`, `vpce_hosts{secretsmanager,kms,sts}` (host only) |
| 2 | database | `aws/database` | `identifier`, `vpc_id`, `subnet_ids`, `allowed_security_group_ids`, `engine_version`, `instance_class`, `multi_az`, `storage_gb`, `max_storage_gb`, `backup_days`, `deletion_protection`, `db_name`, `username`, `timezone`, `kms_key_arn` | `address`, `port`, `db_name`, `username`, `master_secret_arn` (password never in state), `identifier`, `allocated_storage_gb` |
| 3 | container_service | `aws/container-service` | `name`, `image_tag`, `cpu`, `memory`, `min_size`, `max_size`, `max_concurrency`, `health_path`, `environment`, `secrets`, `secret_read_arns`, `bucket_arns`, `kms_key_arns`, `connector_*` | `service_url` (host, no scheme), `service_name`, `service_id`, `service_arn`, `ecr_repository_url`, `instance_role_arn` |
| 4 | object_storage | `aws/object-storage` | `name`, `data_class`, `versioning`, `kms_key_arn`, `force_destroy`, optional CDN read policy | `bucket_id`, `bucket_arn`, `bucket_regional_domain_name` |
| 5 | cdn_edge | `aws/cdn-edge` | `name`, `web_bucket_regional_domain_name`, `api_origin_domain`, `aliases`, `certificate_arn`, `web_acl_arn` | `distribution_id`, `distribution_arn`, `domain_name`, `hosted_zone_id` |
| 6 | secrets | `aws/secrets` | `name`, `kms_purposes`, `generated_secrets`, `placeholder_secrets`, `openai_secret_name`, `recovery_window_days` | `kms_key_arns{purpose}`, `secret_arns`, `secret_field_arns` (`arn:key::` refs), `readable_secret_arns` |
| 7 | email | `aws/email` | `enabled`, `domain`, `zone_id`, `dmarc_policy` | `identity_arn`, `configuration_set`, `send_policy_json` |
| 8 | dns_certs | `aws/dns-certs` | `zones`, `certificates{domain,sans,zone_id}`, `alias_records`, `enable_dnssec` (needs aliased provider `us_east_1`) | `zone_ids`, `name_servers`, `certificate_arns`, `dnssec_ds_records` |
| 9 | waf | `aws/waf` | `name`, `waf_rules` (decoded `platform/waf-rules.json`) (needs aliased provider `us_east_1`) | `web_acl_arn` |
| 10 | observability | `aws/observability` | `name`, `apprunner_service_name/id`, `rds_identifier`, `alarm_emails`, `log_retention_days` | `alerts_topic_arn`, `dashboard_name` |

## Behavioural rules every implementation must keep
- No public data stores; TLS only; encryption at rest (customer-managed key when one is supplied).
- Database password is generated by the platform's secret service, never passed through OpenTofu state.
- The container service exposes a plain `service_url` hostname; no custom resource may be needed to parse it.
- Edge: `/api/*` is never cached and never rewritten to the SPA; SPA rewrite happens only for extension-less non-API paths.
- WAF rule intent comes from `platform/waf-rules.json` (rate limit on auth/signup, managed common + known-bad-inputs, optional geo COUNT).
- Alarms follow KX-21 §13 (5xx > 2 %, p95 > 1.5 s, instances at max, RDS CPU/storage/connections, failover events, Lambda errors).
- Every resource is tagged `Product`, `Env`, `Owner`, `CostCenter`, `KiorlyHostCell`, `KiorlyDataRegion`, `KiorlyStackRole` (+ `KiorlyDataClass` on data stores).
